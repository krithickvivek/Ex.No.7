# Exno.7 - Develop a Prompt-Based Application Tailored to Personal Needs  

### Date:  
### Register No: 212223240075 



## **Aim:**  
To develop a prompt-based application using ChatGPT — demonstrating how to create a prompt-based application to organize daily tasks, showing the progression from simple to more advanced prompt designs and their corresponding outputs.



## **AI Tools Required:**  
- ChatGPT (GPT-4 / GPT-5)  
- Any code editor (VS Code / Google Colab / Jupyter Notebook)  
- Optional: Python API integration for automation  



## **Explanation:**  

A **prompt-based application** uses natural language prompts to interact with an AI model and perform specific tasks.  
This experiment demonstrates how prompt designs evolve from simple instructions to advanced, multi-step commands that handle complex user needs.



## **Example Prompts and Applications**

### **1. Simple Prompt – Daily Task Organizer**  
**Prompt:  List my daily tasks and sort them by priority: work, study, and personal.**  

**Expected Output:**  
- Work: Complete project report  
- Study: Review machine learning notes  
- Personal: Call a friend, go for a walk  



### **2. Moderate Prompt – Study Time Scheduler**  
**Prompt:  Create a study schedule for 5 hours covering AI, Data Structures, and Python. Include short breaks.**  


**Expected Output:**  

| Time | Task |
|||
| 9:00–10:30 | AI Concepts |
| 10:30–10:45 | Break |
| 10:45–12:15 | Data Structures |
| 12:15–12:30 | Break |
| 12:30–2:00 | Python Practice |



### **3. Advanced Prompt – Project Task Breakdown**  
**Prompt:  Break down my ‘Expense Tracker’ web app project into development phases and tasks with estimated completion times.**  


**Expected Output:**  
**Phase 1: Frontend (3 Days)**  
- Design layout (HTML, CSS)  
- Implement functionality (JavaScript)  

**Phase 2: Testing & Debugging (2 Days)**  
- Test input validation  
- Fix UI bugs  

**Phase 3: Documentation (1 Day)**  
- Write README and user guide  



### **4. Advanced Prompt – Personal Budget Manager**  
**Prompt: Create a weekly budget for ₹2000 including food, transport, and entertainment. Suggest savings tips.**  


**Expected Output:**  

| Category | Amount (₹) |
|--|-|
| Food | 800 |
| Transport | 600 |
| Entertainment | 400 |
| Savings | 200 |

**Tip:** Track expenses daily and avoid impulse spending.  



### **5. Advanced Prompt – Travel Itinerary Planner**  
**Prompt:  Plan a 3-day trip to Ooty from Chennai with budget, hotel suggestions, and sightseeing places.**  


**Expected Output:**  
**Day 1:** Arrival, check-in at hotel, visit Botanical Garden  
**Day 2:** Explore Doddabetta Peak, Ooty Lake  
**Day 3:** Local shopping and return trip  

**Estimated Budget:** ₹8,000–₹10,000  



## **Procedure:**  
1. Define the purpose and target user for the prompt-based application.  
2. Identify and construct different prompts ranging from simple to advanced.  
3. Interact with ChatGPT to simulate real user conversations.  
4. Observe how prompt wording affects responses and complexity.  
5. (Optional) Use ChatGPT’s API or Python integration for interactive command-line versions.  



## **Expected Output:**  
A series of functional prompt examples and AI-generated responses showing progression from simple task management to complex, context-aware scheduling or planning.



## **Output (Example Response by LLM):**  

### **Personal Productivity Assistant Features:**  
1. **Daily Task Manager**  
   - Accept tasks via natural language (e.g., “Remind me to call mom at 6 PM”)  
   - Organize tasks by priority and deadline  
   - Provide daily summaries and pending items  

2. **Smart Scheduler**  
   - Schedule events using contextual understanding  
   - Warn about overlapping appointments  

3. **Wellness Tips Generator**  
   - Suggest hydration and exercise reminders  
   - Adapt tips based on user history  



## **Result:**  
The lab exercise resulted in a prototype concept for a **prompt-based personal assistant** powered by large language models. Students were able to:  
- Understand prompt design for real-life applications.  
- Explore creativity through practical, personalized AI solutions.  
- Learn how prompt tuning impacts AI outputs.  
- Experience the flexibility and problem-solving power of LLMs in daily life.
