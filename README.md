# Ex.No: 7  Develop a prompt-based application tailored to their personal needs, fostering creativity and practical problem-solving skills while leveraging the capabilities of large language models.
### Date:  
### Register No:  212223240075

## AIM
To develop a prompt-based application using ChatGPT — to demonstrate how to create a prompt-based application to organize daily tasks, showing the progression from simple to more advanced prompt designs and their corresponding outputs.

## AI TOOLS REQUIRED
- ChatGPT (Large Language Model)  
- Any text editor or command-line interface (for simulation)

## EXPLANATION
This experiment focuses on developing a **personal productivity assistant** using prompt-based interaction with a large language model (LLM).  
The assistant helps users manage their **daily tasks**, **schedule reminders**, **suggest wellness tips**, and **answer general queries** through natural language.  

The system also adapts to the user’s changing preferences over time, simulating a more intelligent and personalized assistant.

## PROMPT
**"Design a personal productivity assistant that can help manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries. The assistant should interact using natural language and be adaptable to the user’s changing preferences over time."**

## PROCEDURE

1. **Define Core Requirements**  
   - Identify the key functionalities of a personal productivity assistant such as task management, scheduling, wellness suggestions, and general query handling.

2. **Design Prompts for Each Feature**  
   - Create specific prompts that interact with the model to achieve desired outcomes:
     - Task management (add, remove, list tasks)
     - Schedule and reminders
     - Wellness tips generation
     - Answering user queries naturally

3. **Simulate User Interaction**  
   - Use a simple command-line interface or chat window to simulate user queries and model responses.  
   - Example:  
     **User:** "Remind me to call mom at 6 PM."  
     **Assistant:** "Got it! I’ll remind you to call mom at 6 PM today."

4. **Collect Feedback and Adapt**  
   - Refine prompts based on user feedback to improve context understanding and personalization.

5. **(Optional) Integrate Memory Simulation**  
   - Store user preferences or past tasks in a basic structure to mimic adaptive learning.

## EXPECTED OUTPUT

### **Personal Productivity Assistant Features**

#### **1. Daily Task Manager**
- Accepts tasks through natural language.  
  *Example:* “Remind me to call mom at 6 PM.”  
- Organizes tasks by **priority** and **deadline**.  
- Provides **daily summaries** and lists **pending items**.

#### **2. Smart Scheduler**
- Schedules events and sets reminders using context understanding.  
- Notifies user of **overlapping appointments** or **free time slots**.

#### **3. Wellness Tips Generator**
- Suggests daily **wellness advice** (hydration, exercise, screen-time breaks).  
- Adapts suggestions based on user preferences and past responses.

#### **4. General Query Assistant**
- Answers everyday questions like weather, quotes, and motivational prompts.

### **Example Interaction**

**User:** "What’s on my schedule today?"  
**Assistant:** "You have 3 tasks: call mom at 6 PM, submit AI report by 8 PM, and attend yoga at 7 AM."  

**User:** "Give me a wellness tip for today."  
**Assistant:** "Remember to take a 5-minute screen break every hour to rest your eyes."  

**User:** "Schedule a meeting with Anusha tomorrow at 10 AM."  
**Assistant:** "Meeting with Anusha set for tomorrow at 10 AM. Shall I add a reminder?"

## RESULT
The lab exercise resulted in the creation of a **prototype concept** for a personal productivity assistant powered by large language models.  
Students were able to:
- Understand how to tailor LLM prompts for real-world applications.  
- Foster creativity by designing assistant features suited to their needs.  
- Learn **prompt engineering techniques** for improved interaction with AI tools.  
- Experience how **generative AI** can simplify daily life and enhance productivity.
